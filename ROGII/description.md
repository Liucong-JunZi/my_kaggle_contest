# 关于本次竞赛

## 一句话总结

地下有很多层岩石。水平井横着钻进，我们知道钻头在三维空间里的精确几何位置，但不知道它现在穿过的是哪一层岩石。你的任务是预测这个。

---

## 背景

开采石油或天然气时，地质师会先找到**目标产层**（比如含油的砂岩层）。为了最大化产量，会打**水平井**——先垂直向下钻，到达目标层后拐弯，横着穿过目标层钻进几千英尺。

问题是：**地下的岩层不是平的**，它们有起伏、倾斜。所以钻头虽然几何上是横着走的，但实际上可能一会儿在上面的岩层，一会儿钻到下面的岩层。如果钻头跑出了目标产油层，就采不到油气了。

因此，必须实时知道：**钻头现在到底在哪一层岩石里？**

---

## 已知信息

### 水平井（要预测的对象）

提供了一口水平井的全部数据：

- **几何轨迹**：每个点的三维坐标（X, Y, Z）和沿井眼的长度（MD）
- **GR 值**：钻头所在位置测到的岩石放射性读数

简单说：**我们知道钻头在空间的哪个点，以及该点的岩石放射性是多少。**

### 垂直参考井（Typewell，用于对比）

还提供了一口**垂直井**的数据。这口井从上往下直直地穿过所有岩层，像一本完整的"地层目录"：

- 每一英尺的深度（TVT）
- 该深度的 GR 值
- 该深度的岩层名称（如 EGFDL、BUDA）

简单说：**我们知道每个深度对应什么岩层，以及该岩层的放射性特征。**

### 关键原理

**同一岩层的 GR 值是相似的。** 所以，tvt如果水平井某个位置的 GR 值和垂直井 4850ft 处的 GR 值很像，那水平井这个位置大概率对应的就是 4850ft 那个岩层。

---

## 目标变量：TVT

**TVT 就是"水平井上每个点，对应垂直参考井上的深度坐标"。**

| | 水平井 | 垂直参考井 |
|---|---|---|
| 深度系统 | MD（沿井眼长度） | TVT（垂直深度索引） |
| 已知 | MD、X、Y、Z、GR | TVT、GR、Geology |
| 未知 | **TVT（目标）** | — |

通过对比 GR 值，把水平井上的点"映射"到垂直参考井的深度上，得到 TVT。知道了 TVT，就能查表知道是什么岩层。

## 文件说明

### train/ — 训练数据（每口井三个文件）

#### 1. {WELLNAME}__horizontal_well.csv — 水平井数据

| 字段 | 说明 |
|------|------|
| **WELLNAME** | 井名 |
| **MD** | 测量深度（ft）：从地面沿井眼轨迹到该点的累计长度 |
| **X** | 东坐标（ft） |
| **Y** | 北坐标（ft） |
| **Z** | 真垂直深度（ft）：该点低于海平面的垂直距离 |
| **GR** | 自然伽马（API）：该点的岩石放射性读数 |
| **ANCC / ASTNU / ASTNL / EGFDU / EGFDL / BUDA** | 地质模型预测的**各构造面深度**（ft，与 Z 同坐标系）。例如 `ANCC=-9395` 表示在当前 (X,Y,Z) 位置，ANCC 构造面的预测深度为 -9395 ft。**注意**：这些列名和 typewell 中的岩层名称相同，但含义不同——这里不是岩层标签，而是该构造面的深度数值。由地质模型估算，非实测（仅训练集） |
| **TVT_input** | TVT 的副本，作为特征。**仅水平井"已知段"（井口到造斜段）有值，水平评价段为 NaN**。训练集和测试集均有此列，且同一口井的非空范围一致 |
| **TVT** | **目标变量**：该点在垂直参考井上对应的深度坐标（ft，仅训练集） |

#### 2. {WELLNAME}__typewell.csv — 垂直参考井（地层目录）

| 字段 | 说明 |
|------|------|
| **TVT** | 垂直深度索引（ft）：垂直井的主深度坐标 |
| **GR** | 该深度的岩石放射性读数 |
| **Geology** | 该深度的岩层名称 |

#### 3. {WELLNAME}.png — 可视化图

### test/ — 测试数据

约 200 口井，每口井两个文件（水平井 + 垂直参考井）。水平井的评价段 TVT 被隐藏（NaN），需要预测。水平井包含 TVT_input（已知段有值，评价段为 NaN）。

### 三、建模建议

| 数据/列 | 处理建议 |
|---------|---------|
| MD、X、Y、Z、ASTNU、ASTNL、EGFDU、BUDA、TVT | 直接使用，无需处理 |
| ANCC、EGFDL（构造面深度） | 7+1 口井完全缺失，可用同井其他构造列或全局均值填充。注意这些是深度数值，不是岩层标签 |
| horizontal_well.**GR** | **重点处理**：线性插值、用 typewell GR 辅助填充、引入缺失掩码特征 |
| typewell.**GR** | 100% 完整，可作为参照基准 |
| typewell.**Geology** | 缺失较多，需做缺失值处理或编码时考虑 |
| TVT_input | 已知段的 TVT 值，可作为特征使用；评价段为 NaN |
